# Side navigation

Projects opens the project library. Recent opens the collection history, with collection and project name search. Favourites opens favourite projects; its badge counts projects, not collections.

Quick access shows the six most recently opened, available collections. View all recent shows up to 100 locally remembered visits. Opening a collection moves it to the top; autosave does not. Archived collections and projects absent from the current library are excluded. A moved project can be opened again through Open project. History starts accumulating after this feature is installed; modification dates are not treated as past visits.

Favourite projects group their active collections. Select a project to resume it, or a collection to open that collection directly. The heart in the open project's toolbar adds or removes the project from favourites. The plus beside Projects creates a project.

Ctrl+1, Ctrl+2 and Ctrl+3 open Projects, Recent and Favourites. On macOS use Command. These bindings can be changed in Settings under Editing & shortcuts. Arrow keys, Home and End move between visible sidebar buttons; Enter activates the focused button. Typing in an editor keeps its normal keyboard behaviour.

The application remembers sidebar visibility and expanded sections locally. Opening a different collection reveals its quick-access or favourite group. History and disclosure preferences are best effort and are not written into project files.
