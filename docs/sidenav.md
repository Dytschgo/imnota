# Side navigation

Projects opens the project library. Recent opens the collection history, with collection and project name search. Favourites opens favourite projects; its badge counts projects, not collections.

Quick access shows the six most recently opened, available collections. View all recent shows up to 100 locally remembered visits. Opening a collection moves it to the top; autosave does not. Archived collections and projects absent from the current library are excluded. A moved project can be opened again through Open project. History starts accumulating after this feature is installed; modification dates are not treated as past visits.

Pinned lists favourite projects alphabetically, each with its active collection count; archived projects are left out. Select a pinned project to open it. Hover or focus a Recent row and choose the pin to pin its project, or choose the pin again, or the unpin button on a Pinned row, to remove it. Pinning sets the same project favourite flag as the heart in the open project's toolbar and the Favourites filter on the Projects page, so it is stored in the project file and works without opening the project. The plus beside Projects creates a project.

Ctrl+1, Ctrl+2 and Ctrl+3 open Projects, Recent and Favourites. On macOS use Command. These bindings can be changed in Settings under Editing & shortcuts. Arrow keys, Home and End move between visible sidebar destinations; Tab also reaches each row's pin button. Enter activates the focused button. Typing in an editor keeps its normal keyboard behaviour.

The application remembers sidebar visibility and expanded sections locally. Opening a different collection reveals its quick-access group. History and disclosure preferences are best effort and are not written into project files.
