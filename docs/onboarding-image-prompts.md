# Optional onboarding artwork prompts

The shipped onboarding demo does not require generated artwork. Its interactive screenshot is drawn by browser canvas code and stays in memory. These prompts are an optional future layer for the welcome or completion state; they must not replace the working sample.

## Direction

Use a calm, voice-tool-inspired visual rhythm: precise dark graphite surfaces, one saturated indigo signal, soft depth, generous negative space, and a sense that a rough thought is becoming a clear instruction. Draw an original composition rather than reproducing Wispr Flow branding, logos, interface, or proprietary assets.

## Welcome artwork

```text
Create a polished editorial product illustration for Imnota, a local desktop tool that turns annotated screenshots into Markdown and PNG prompt bundles for coding agents. Landscape composition, 3:2 ratio, dark graphite background. Show one crisp screenshot plane entering from the left, a small red annotation rectangle and concise text note being attached in the center, and a paired PNG plus Markdown handoff leaving on the right. Use restrained indigo as the only identity accent, with thin cyan reserved for a subtle data-transfer cue. Soft dimensional lighting, precise edges, quiet negative space, no gradients in text, no floating generic app icons, no people, no testimonials, no cloud symbols, no AI robot imagery, no third-party logos, no legible UI copy. The result should feel fast, calm, local, and technically exact. Leave safe empty space for a short heading outside the artwork. Original visual language, inspired by the clarity and fluidity of premium voice-product art direction without copying any brand.
```

## Completion artwork

```text
Create an original compact completion illustration for Imnota onboarding, landscape 4:3 ratio on transparent or flat graphite background. A single annotated screenshot and a Markdown document align into one tidy clipboard-ready pair, with a precise check mark formed by the spacing between them rather than a large badge. Indigo selection color, neutral white document surface, one red annotation mark, restrained soft shadow with visible downward offset. No confetti, trophies, fireworks, clouds, bots, generic sparkles, third-party logos, testimonials, or legible interface text. The image should communicate that visual context and written instructions now match. Premium desktop productivity-tool finish, calm and exact, with an original composition.
```

## Delivery notes

- Export at 2× the final display size in PNG.
- Keep all meaningful shapes inside a 10% safety margin.
- Provide dark-background and transparent-background variants.
- Record the exact generation prompt in the asset metadata or adjacent provenance note.
- Verify readability in both application themes; artwork must not carry essential instructional text.
