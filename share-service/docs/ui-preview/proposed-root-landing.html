Imnota stays local-first. When you need a second pair of eyes, publish only the generated Markdown + prompt PNGs to a secret read-only link. No account, no project folder, no annotation source.

The desktop app never auto-uploads. Sharing is always a separate button with a privacy confirm. Links are unguessable, expire (30 days default), and can be revoked instantly.

How it works

1

Pair this browser

Open /new, create a one-time code. It expires in 10 minutes and works for exactly one upload.

2

Publish from Imnota

Paste the code in the desktop app. It sends prompt.md + included PNGs only. ZIP is built on the server.

3

Send the link

Share /s/<token>. Anyone with the link can read. No login. Revoke anytime.

Shared

  • Generated Markdown
  • Included prompt PNGs
  • Optional server-built ZIP

Never shared

  • Project folder, source screenshots
  • Annotation / drawing JSON, recovery files
  • Settings, paths, secrets
